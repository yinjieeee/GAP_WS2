\section{Optimization Process}

\label{sec:opt_process}

本節展示六組數據的最佳化收斂歷程，包含 $\beta$ 排程、FOM 曲線與模態純度演化，用以驗證 $\beta$ 漸進策略的數值穩定性。

\subsection{Beta Continuation Schedule and FOM Convergence}

\label{ssec:opt_FOM}

所有數據均採用相同的 $\beta$ 排程：從 $\beta = 4$ 出發，依固定迭代間隔增至最終 $\beta = 512$，每次 $\beta$ 切換以紫色垂直線標示 (見圖~\ref{fig:FOM_history_all})。FOM 曲線在各組數據的 $\beta < 16$ 階段均呈大幅上升趨勢，並在此區間的末期達到數值最高點。此收斂模式反映了低 $\beta$ 階段較寬鬆的邊界條件允許優化器在連續密度空間中快速探索，從而有效尋獲全域較優的拓撲佈局並達到最高性能。

低拓樸荷 $\ell = 0, 1$ 的 FOM 最終值 ($0.39$, and higher) 顯著高於高拓撲荷 $\ell = 3, 4, 5$ (FOM $\approx 0.30$ 至 $0.19$)，這表明更高階的 OAM 模態需要更複雜的相位調制，因而限制了最終的耦合效率。值得注意的是，儘管 $\ell = 3$ 的 FOM 數值略低，但在 $\beta$ 切換後的性能恢復速度依然極快，說明拓撲荷的增加並未使最佳化收斂特性顯著惡化。

\subsection{Mode Purity Convergence}

\label{ssec:opt_purity}

圖~\ref{fig:purity_history_all} 呈現六組數據的模態純度收斂歷程。purity演化歷程與 FOM 歷程相似，均於前期迅速建立主體結構，並在第 2 至 4 次 $\beta$ 切換後即達到飽和與穩定。

低拓樸荷 $\ell = 0, 1, 2$ 的最終 Purity 均超過 $96\%$，其中 $\ell = 1$ 達到六組中最高的 $98.66\%$，表明此設計條件下最佳化的解品質最為優秀。隨拓樸荷提升，$\ell = 3$ Purity 降至 $94.13\%$，而 $\ell = 4$ 與 $\ell = 5$ 則進一步降至 $81.94\%$ 與 $82.62\%$。高拓樸荷數據中，現有 4.5 $\mu\text{m}$ 的設計區域空間尺寸限制、解析度不足，高階 OAM 模態已達物理極限。因此純度在優化初期就碰到瓶頸，後期即便調高 $\beta$ 值，也只是引發結構的邊界振盪，無法再提升最終純度。

LCP 強度分佈 (各組右上) 在所有數據中均集中於結構中央區域 ($\sim 1\ \mu\text{m}$ 尺度)，呈現非均勻的局域化增強，反映最佳化結構對 LCP 偶極輻射的近場收集效率。LCP 相位分佈 (各組左上) 受結構散射影響而呈現複雜的空間分佈，與遠場的有序螺旋相位形成對比，顯示近場的相位調制是透過散射效應的集體作用而非局域的相位延遲。

RCP 分量 (各組下排)的強度明顯低於 LCP 分量，兩者的歸一化強度比較直接反映了結構對圓偏振的選擇性 (見第~\ref{sec:pol_selectivity} 節)。各數據的 RCP 強度分佈形態因設計而異，但均未表現出與 LCP 相同的集中近場增強，表明最佳化結構確實對 K 谷 LCP 輻射具有選擇性的近場耦合。

\section{Far-Field LG Mode Performance}

\label{sec:farfield}

圖~\ref{fig:farfield_all} 以四格子圖形式比較六組數據在 $z = 10\,z_R$ 遠場評估平面的模擬 LCP 相位與強度 (上排)，以及目標 LG$_{\ell,0}$ 模態的理論相位與強度 (下排)。

\textbf{強度分佈：}$\ell = 0$ 遠場呈現中心峰值的高斯輪廓；$\ell \geq 1$ 的所有數據均呈現中心強度為零的環形光斑，且環形半徑隨 $\ell$ 增大，與 LG 模態理論預期相符 (峰值半徑 $r_\text{peak} = w_0\sqrt{\ell/2}$)。高拓樸荷數據 $\ell = 4, 5$ 的環形光斑輕微不均。

\textbf{相位分佈：} $\ell = 0$ 至 $2$ 數據的遠場相位均清晰呈現對應的螺旋結構。相位螺旋的臂數與旋轉方向和目標模態完全對應，定性驗證了各設計的拓樸荷正確性 (詳細量化驗證見第~\ref{sec:winding} 節)。然而，高拓樸荷數據 $\ell = 3$ 至 $5$ 的相位螺旋臂於強度中心處無法如低拓樸荷般完美對齊，在 $\ell = 4$ 與 $5$ 時更呈現些許雜亂，此偏差反映了有限設計空間下高階 OAM 模態整形的固有難度。

\textbf{量化結果：}六組數據的 Purity 與 $|\text{Overlap}|^2$ 已列於表~\ref{tab:results_summary}。整體趨勢顯示，Purity 隨 $\ell$ 增大而降低，在 $\ell \leq 3$ 範圍內均超過 $94\%$，$\ell = 4, 5$ 則降至約 $82\%$。$|\text{Overlap}|^2$ 則由 $\ell = 0$ 的 $60.92$ 大幅下降至 $\ell \geq 4$ 的 $4.00$ 以下。由於監測區域已依各拓樸荷的光斑尺寸動態調整以確保固定涵蓋比例，此顯著衰減並非源於幾何截斷，而是反映了在有限設計空間下，結構對高階 OAM 模態調控能力受限所導致的模態純度下降與空間能量散射。

\section{Optical Chirality}
\label{sec:chirality}
光學手性密度 $C \propto -\omega\,\varepsilon_0\,\text{Im} (\mathbf{E}^* \cdot \mathbf{B})$ 可量化空間中電磁場的手徵特性：$C > 0$ 對應 LCP 主導，$C < 0$ 對應 RCP 主導。本節首先以高階模態 ($\ell = 5$) 為代表，剖析光學手性沿傳播軸 ($z$ 軸) 的演化機制，隨後進一步對比六組數據在近場與遠場平面的手性分佈特徵。

\subsection{Chirality Propagation}
\label{ssec:chirality_prop}
為了釐清光束傳播過程中的手性演化物理機制，圖~\ref{fig:chirality_prop_l5} 呈現了 $\ell = 5$ 模態從近場 ($z \approx 0^+$) 傳播至遠場 ($z = 10\,z_R$) 的光學手性密度分佈切面。

結果顯示，近場區域 ($z \ll z_R$) 呈現明顯的 LCP/RCP 混合態，且受拓樸結構強烈的局域散射與漸逝波耦合影響，點光源上方過半區域展現藍色的 LCP 主導特徵 ($C > 0$)。然而，隨著傳播距離 $z$ 增加，非輻射性的漸逝波迅速指數衰減，局域散射場趨於零；當光束進入遠場輻射區 ($z \ge z_R$) 後，最終由傳播場完全主導，使光學手性恢復為純粹且均勻的 RCP 態 ($C < 0$)，與光源手性一致。此演化過程完整證實了遠場傳播場能完美保留光源的 RCP 手性純度。

\section{Phase Winding Verification}

\label{sec:winding}

相位纏繞分析是驗證遠場渦旋光束拓樸荷的直接方法：在遠場強度峰值半徑 $r_\text{peak}$ 的圓形路徑上取樣 LCP 電場相位，展開後計算角向總相位變化量，理想情況下應等於 $\ell \times 2\pi$。

圖~\ref{fig:winding_all} 呈現六組數據的相位纏繞驗證結果。各數據在對應 $r_\text{fraction}$ (峰值半徑與評估區域半徑之比)的圓形路徑取樣後，展開相位 (橙色實線) 與理想 $\ell \times 2\pi$ 線性斜率 (黑色虛線) 的吻合程度如下：

  

\begin{itemize}
	\item $\ell = 0$ (017，$r_\text{frac} = 0.200$)：展開相位趨近於零 ($\approx 0 \times 2\pi$)，與高斯光束的零拓樸荷一致。
    \item $\ell = 1$ (018，$r_\text{frac} = 0.3885$)：展開相位總量 $= 1.00 \times 2\pi$，誤差 $< 0.1\%$。
    \item $\ell = 2$ (013，$r_\text{frac} = 0.4878$)：總量 $= 1.99 \times 2\pi$，誤差 $0.5\%$。
    \item $\ell = 3$ (020，$r_\text{frac} = 0.5468$)：總量 $\approx 3.00 \times 2\pi$，誤差 $< 1\%$。
    \item $\ell = 4$ (021，$r_\text{frac} = 0.5868$)：總量 $\approx 4.00 \times 2\pi$，誤差 $< 1\%$。
    \item $\ell = 5$ (022，$r_\text{frac} = 0.6176$)：總量 $\approx 5.00 \times 2\pi$，誤差 $< 1\%$。
\end{itemize}

所有數據的展開相位均與理論預期高度吻合，精確驗證了各設計確實在遠場產生了目標拓樸荷的渦旋光束。儘管 $\ell = 4, 5$ 的強度環形存在輕微的角向不均勻性 (見第~\ref{sec:farfield} 節)，其相位纏繞仍精確呈現對應拓樸荷，表明高 Purity 的喪失主要源於強度輪廓的偏差，而非相位奇點的失位或拓樸荷的改變。

\section{Circular Polarization Selectivity}
\label{sec:pol_selectivity}
為確認最佳化奈米結構是否能精準篩選偏振，本節進行了偏振交叉激發測試。在谷電子學應用中，WS$_2$ 單層材料的 $K$ 谷與 $K'$ 谷激子會分別發射 LCP 與 RCP 光；因此，結構必須能辨識特定的偏振態，同時抑制非目標偏振的耦合。

模擬的拓樸結構皆以 LCP 點光源進行拓樸最佳化。為了定量檢驗其篩選能力，我們以 $\ell = 3$ 結構為代表，將輸入光源改為反向偏振的 RCP 點光源，並評估遠場 OAM 模態純度。

測試結果顯示，當改用 RCP 光源激發這套 LCP 最佳化結構時，遠場目標 $\ell = 3$ 的純度僅 $0.84\%$。此極低的純度與原本 LCP 光源下高效轉換的結果形成鮮明對比，直接證明該結構具備極強的圓偏振篩選能力。

這種偏振選擇性源於奈米結構內部的幾何相位與近場非對稱散射。當非目標偏振 (RCP) 入射時，結構無法滿足 OAM 模態整形所需的幾何相位條件，導致絕大部分能量散射為雜散場，無法有效耦合至遠場目標模態。
