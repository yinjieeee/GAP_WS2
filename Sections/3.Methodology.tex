\chapter{Methodology}

\label{ch:Methodology}

電磁模擬、物理建模與拓樸最佳化構成本章的三條主軸。整體研究流程分為五個階段：

1. 模型建置：於 MEEP 中建立含鑽石基板、$\text{WS}_2$ 發光層與拓樸最佳化設計區域的三維電磁模型，並定義圓偏振點光源。

2. 拓樸最佳化參數化：以連續密度變數描述設計區域的材料分佈，並透過密度過濾與投影方法確保結構的可製造性與二值化。

3. 伴隨法最佳化迴圈：以正向模擬取得近場分佈，經近遠場轉換計算遠場複振幅，與目標 LG 模態進行重疊積分作為目標函數，並透過伴隨法求解梯度，以 MMA 演算法迭代更新設計變數。

4. 遠場重建與傳播分析：最佳化完成後針對最佳結構重新執行模擬，取得多重傳播距離下的遠場分佈。

5. 性能評估：以模態純度、重疊積分、相位繞數、近/遠場光學手性等指標定量評估最終結構的性能。


\section{Numerical Simulation Methods and Tools}

\subsection{Finite-Difference Time-Domain Method}

電磁模擬以時域有限差分法 (Finite-Difference Time-Domain, FDTD) 求解 Maxwell 方程式：

\begin{align}
\nabla \times \mathbf{E} = -\frac{\partial \mathbf{B}}{\partial t}, \qquad
\nabla \times \mathbf{H} = \frac{\partial \mathbf{D}}{\partial t} + \mathbf{J}, \qquad
\mathbf{B} = \mu \mathbf{H}, \qquad
\mathbf{D} = \varepsilon \mathbf{E}
\end{align}

FDTD 方法由 Yee 於 1966 年提出，將電場與磁場分量交錯配置於空間網格節點 (Yee cell)，以蛙跳格式在時間域數值迭代\cite{yee1966numerical}。數值穩定性受 Courant–Friedrichs–Lewy (CFL) 條件約束，即

\begin{align}
\Delta t \le \frac{1}{c\sqrt{(1/\Delta x)^2 + (1/\Delta y)^2 + (1/\Delta z)^2}}
\end{align}
(後續式都要+1)

其中，$\Delta t$ 為時間步長，$c$ 為真空或介質中的光速，$\Delta x$、$\Delta y$ 與 $\Delta z$ 分別代表沿 $x$、$y$、$z$ 方向上的空間網格大小。計算域邊界採用完全匹配層 (Perfectly Matched Layer, PML) 吸收邊界條件，以模擬開放輻射邊界、抑制人工反射\cite{berenger1994aperfecctly}。

\subsection{Simulation Environment and Computational Setup}

MEEP (MIT Electromagnetic Equation Propagation) 是一套開源 FDTD 軟體套件，支援任意非均勻介質分佈、寬頻脈衝激發與並行計算\cite{Oskooi2009meep}。其伴隨法延伸模組將正向模擬、伴隨模擬、材料內插與投影映射整合為一可微分的計算圖，使目標函數對設計變數的梯度得以透過自動微分框架高效計算\cite{Hammond2022high}。

\section{Physical Model and Setting}

\subsection{Simulation Geometry}

模擬計算域採用三層垂直堆疊結構：底部為鑽石 (diamond) 高折射率基板，中間為單層 $\text{WS}_2$ 激發層，頂部為拓樸最佳化設計層 (GaP/空氣二元材料) ，設計層上方設置近場監測面，計算域四周與上下邊界以 PML 封閉。圓偏振點光源位於 $\text{WS}_2$ 層，其發出的光場向上通過設計層，由近場監測面採集後經近遠場轉換 (Near-to-Far Field Transformation, N2F)傳播至遠場觀察平面。

\subsection{$\text{WS}_2$ Dipole Source and Valley Selection Rule}

$\text{WS}_2$ 單層中單一激子的自發輻射在物理上可視為一電偶極源。在模擬中，依據 K/K′ 谷選擇定則，採用下列正交電偶極組態模擬圓偏振自發輻射：

\begin{align}
\mathbf{p}(t) = p_0\!\left[\hat{x}\,e^{-i\omega_0 t} + i\,\hat{y}\,e^{-i\omega_0 t}\right] f(t)
\end{align}

其中 $f(t)$ 為時域包絡函數，$\hat{x}$ 與 $\hat{y}$ 分量振幅相等、相位相差 $90^{\circ}$，合成左旋圓偏振的點光源，對應 K 谷激子躍遷的手徵圓偏振態。此為理想化的單一圓偏振等效點光源，未考慮 $\text{WS}_2$ 中實際激子的非均向性躍遷矩或多能谷疊加效應。

\subsection{Chirality Definition}

光學手性密度 (optical chirality density) 依 Tang and Cohen 於 2010 年提出的定義為\cite{tang2010optical}

\begin{align}
C = \frac{\varepsilon_0\,\omega}{2}\,\text{Im}\!\left(\mathbf{E}^{*}\cdot\mathbf{H}\right)
\end{align}

在 MEEP 的歸一化單位制中 ($\varepsilon_0=\mu_0=c=1$，$\omega = 2\pi f$)，此式化簡為

\begin{align}
C = \pi f\,\text{Im}\!\left(\mathbf{E}^{*}\cdot\mathbf{H}\right)
\end{align}

為量化局部場相對於理想圓偏振平面波的手性增強程度，進一步定義增強因子 (enhancement factor，$g$-factor)：

\begin{align}
g = \frac{|C|}{C_{CPL,vac}}
\end{align}

其中 $C_{CPL,vac}$ 為單位振幅圓偏振平面波於真空中的手性密度參考值，定義慣例參考 Hendry 等人於 2010 年的超手性場研究\cite{hendry2010ultrasensitive}。式 (3.4) 至 (3.6) 適用於近場與遠場任意位置的手性評估。

\subsection{LG Mode Projection}

最佳化目標是使遠場光場逼近特定模態指標 $(l, p)$ 的拉格耳–高斯 (Laguerre–Gaussian, LG) 光束。LG 模態複振幅場 $U_{l,p}(\rho,\phi,z)$ 的完整推導已於 Section  2.1.3 說明；此處直接以其組建左旋圓偏振 (LCP) 目標場：

\begin{align}
\mathbf{E}_{target} = \frac{U_{l,p}}{\sqrt{2}}\hat{x} + \frac{i\,U_{l,p}}{\sqrt{2}}\hat{y}
\end{align}

透過功率歸一化 ($\int |\mathbf{E}_{target}|^2\, dA = 1$)，消除絕對強度的差異，使分析能夠聚焦於相位分佈與相對強度輪廓的結構特徵。給定遠場複振幅 $\mathbf{E}_{ff} = (E_{ff,x}, E_{ff,y})$，模態重疊積分 (mode overlap integral) 定義為

\begin{align}
\text{Overlap} = \int_{A} \!\left(E_{ff,x}\,E_{target,x}^{*} + E_{ff,y}\,E_{target,y}^{*}\right)\! dA
\end{align}

\subsection{Purity Calculation}

基於式 (3.8) 的重疊積分，模態純度定義為

\begin{align}
\text{Purity} = \frac{|\text{Overlap}|^2}{P_{sim}\cdot P_{target}}, \qquad P_{sim} = \int_A \!\left(|E_{ff,x}|^2+|E_{ff,y}|^2\right)\!dA,\quad P_{target}=1
\end{align}

模態純度是介於 0 (完全不匹配) 至 1 (完全匹配) 的比值量，對場的絕對強度不敏感。意即， $P_{sim}$ 趨近於 0 時， Purity 仍可能維持高值。因此，此特性不適合直接作為最佳化的目標函數；但仍適用於評估最終結構與目標 LG 模態的形狀匹配程度。

\section{Optimization Algorithms and Workflow}

本節依據實際最佳化先後步驟展開討論：定義設計變數的材料參數化 (3.3.1) ，繼而說明過濾與投影映射 (3.3.2) ，接著介紹計算最佳化目標所需的 N2F 轉換 (3.3.3) 與目標函數定義 (3.3.4) ，最後說明梯度計算 (3.3.5) 與更新演算法 (3.3.6)。

\subsection{Topology Optimization}

拓樸最佳化以設計架構內每一空間點的材料密度 $\rho(\mathbf{x})\in[0,1]$ 作為設計變數，透過迭代數值最佳化在連續密度空間中搜尋最佳材料分佈\cite{bendsøe1988generating, sigmund2013topology}。此框架的核心優勢在於不須預設結構拓撲，允許設計空間內的幾何形態自由增減與演變，相較於參數化設計方法具有更高的設計自由度。

設計區域的有效介電函數透過材料內插關係式決定：

\begin{align}
\varepsilon(\mathbf{x}) = \varepsilon_{A} + \bar{\rho}(\mathbf{x})\,\bigl(\varepsilon_{B} - \varepsilon_{A}\bigr)
\end{align}

其中 $\varepsilon_A$、$\varepsilon_B$ 分別為兩種候選材料的介電函數，$\bar{\rho}$ 為經過密度過濾與投影處理後的材料物理密度 (見 3.3.2 節) 。數值模擬中，設計區域經由網格離散化後，共含約 $5\times10^4$ 個設計變數。每次的最佳化迭代以伴隨法計算所有設計變數對於 FOM 的梯度，隨即輸入 MMA 的梯度求解器，用以更新設計區域內的材料密度分布。

\subsection{Filtering and Projection}

為避免棋盤格效應並考慮最小特徵尺寸限制，原始設計變數 $\rho$ 先經錐形過濾器 (conic filter) 平滑化\cite{lazarov2011filters}：

\begin{align}
\tilde{\rho}(\mathbf{x}) = \frac{\displaystyle\sum_{i} w(|\mathbf{x}-\mathbf{x}_i|)\,\rho_i}{\displaystyle\sum_{i} w(|\mathbf{x}-\mathbf{x}_i|)}, \qquad w(r) = \max(0,\; R - r)
\end{align}

其中 $R$ 為過濾半徑，由目標最小特徵尺寸與侵蝕閾值反推得值。過濾後的密度 $\tilde{\rho}$ 再經雙曲正切投影 (tanh projection) 逼近二元分佈\cite{wang2011projection}：

\begin{align}
\bar{\rho}(\mathbf{x}) = \frac{\tanh(\beta\eta) + \tanh\!\left(\beta\bigl(\tilde{\rho}(\mathbf{x})-\eta\bigr)\right)}{\tanh(\beta\eta) + \tanh\!\left(\beta(1-\eta)\right)}
\end{align}

其中 $\eta$ 為投影閾值，$\beta$ 為控制投影陡峭程度的參數：$\beta\to 0$ 時 $\bar\rho\approx\tilde\rho$ (近似線性，結構呈灰階分佈)；$\beta\to\infty$ 時 $\bar\rho$ 趨近嚴格二元分佈。由於高 $\beta$ 值下投影函數的梯度趨於陡峭甚至不連續，直接以高 $\beta$ 值最佳化容易使梯度下降法陷入局部解，故採用 $\beta$ 值連續遞增策略：最佳化過程分為多個階段，每一階段固定一個 $\beta$ 值迭代收斂後，再切換至更大的 $\beta$ 值，逐步將結構由灰階逼近至二值化。

\subsection{Near-to-Far Field Transformation}

設計區域上方的近場監測面記錄完整的電磁場分量後，經近遠場轉換 (Near-to-Far Field Transformation, N2F) 便可得到遠場的模態分佈。N2F 方法基於電磁等效原理\cite{taflove2005computational, balanis2016antenna}：將監測面上的 $\mathbf{E}$、$\mathbf{H}$ 場等效為一組面電流與面磁流源

\begin{align}
\mathbf{J}_s = \hat{n}\times\mathbf{H}, \qquad \mathbf{M}_s = -\hat{n}\times\mathbf{E}
\end{align}

再以自由空間並矢格林函數 (free-space dyadic Green's function) 將此等效源傳播至任一遠場觀察點，得到

\begin{align}
\mathbf{E}_{ff}(\mathbf{r}_{ff}) = \mathcal{G}\!\left[\mathbf{E}_{near},\, \mathbf{H}_{near}\right]
\end{align}

其中 $\mathcal{G}$ 為近遠場轉換算子。在最佳化階段，引入可微分的近遠場架構，使 FOM 的伴隨梯度得以映射回 $\mathcal{G}$，進而計算出準確的梯度。而在最佳化完成後，則基於相同的物理與數學原理，可以重建遠場輻射場數據。

\subsection{Figure of Merit}

式 (3.9) 的 Purity 本質上是無因次比值，對電磁場的絕對強度不敏感。若單以此做為目標函數易衍生弊端：當模擬總功率 $P_{sim}\to 0$ 時，Purity 可能呈現偽收斂值，使最佳化器收斂至耦合效率極低的病態解。為避免此問題並兼顧能量傳輸效率，引入對絕對重疊強度的對數正則化項：

\begin{align}
\text{FOM} = \log\!\left(\text{Purity}+\epsilon\right) \;+\; \alpha\,\log\!\left(|\text{Overlap}|^2+\epsilon\right)
\end{align}

其中 $\epsilon = 10^{-30}$ 為避免對數運算發散的數值穩定項。將式 (3.9) 代入並利用 $P_{target}=1$，可化簡為：

\begin{align}
\text{FOM} = (1+\alpha)\,\log\!\left(|\text{Overlap}|^2\right) \;-\; \log\!\left(P_{sim}\right)
\end{align}

由式 (3.16) 可見，FOM 實質上是加權後的重疊強度對數扣除模擬總功率對數，其中權重 $\alpha$ 控制最佳化器在模態形狀匹配 (純度)與絕對耦合效率間的相對重視程度：$\alpha=0$ 時 FOM 退化為單純的對數純度；$\alpha$ 增大則加重對絕對耦合功率的要求。最佳化求解預設以最小化為方向，故程式實作中回傳 $-\text{FOM}$ 作為最小化目標。

\subsection{Adjoint Method}

設計變數梯度 $\partial \text{FOM}/\partial \rho_j$ 若以有限差分逐一擾動計算，其計算成本與設計變數數目 $N$ 成正比：以約 $5\times10^4$ 個設計自由度而言，此方式不具實用性。伴隨法僅需兩次額外的電磁模擬 (一次正向、一次伴隨)，即可取得對所有設計變數的梯度，計算成本與 $N$ 無關\cite{lalau2013adjoint}：

\begin{align}
\frac{\partial \text{FOM}}{\partial \rho_j} \;\propto\; \text{Re}\!\left[\int_{\Omega_j} \mathbf{E}_{adj}(\mathbf{r}) \cdot \frac{\partial \varepsilon(\mathbf{r})}{\partial \rho_j}\,\mathbf{E}_{fwd}(\mathbf{r})\; dV\right]
\end{align}

其中 $\mathbf{E}_{fwd}$ 為正向模擬所得的電磁場，$\mathbf{E}_{adj}$ 為以 FOM 對電磁場的偏微分作為虛擬光源、反向注入計算區域所得的伴隨電磁場，$\partial\varepsilon/\partial\rho_j$ 由式 (3.10) 的材料內插關係式決定。

在含有密度過濾與投影映射的框架下，FOM 對原始設計變數 $\boldsymbol{\rho}$ 的完整梯度須透過連鎖律逐層反向映射：

\begin{align}
\frac{\partial \text{FOM}}{\partial \boldsymbol{\rho}} = \frac{\partial \text{FOM}}{\partial \bar\rho}\cdot \frac{\partial \bar\rho}{\partial \tilde\rho}\cdot \frac{\partial \tilde\rho}{\partial \boldsymbol{\rho}}
\end{align}


利用基於自動微分框架的伴隨最佳化模組，將式 (3.14) 的 N2F 轉換算子、式 (3.15) 的 FOM 以及式 (3.18) 的過濾/投影鏈整合為一可微分計算圖，使梯度得以自動反向傳播至原始設計變數 $\boldsymbol{\rho}$。

\subsection{MMA}

取得梯度後，以 Method of Moving Asymptotes (MMA) 演算法迭代更新設計變數\cite{svanberg1987method}。MMA 是一種凸可分離規劃方法：每一次迭代均利用當前點的梯度資訊，在設計空間中建立易於求解的近似子問題。此子問題在結構上滿足凸性與可分離性，並透過動態修正的「移動漸近線（moving asymptotes）」來約束搜尋步幅，藉此兼顧收斂的穩定性與計算效率。

\section{Simulation Parameters and Implementation}

具體材料選擇、幾何設定、最佳化排程參數與後處理評估設定集中於此節說明。

\subsection{Material System and Parameters}

數值模型的材料設定如下：底部鑽石基板折射率 $n = 2.40$；$\text{WS}_2$ 激發層同樣取 $n = 2.40$，厚度設定為 $1/\text{resolution}$ (最小可解析厚度，近似原子級單層)，以固定實數折射率近似光學響應，未計入色散與吸收虛部。設計層採用 GaP (磷化鎵，$n = 3.31$) 與空氣 ($n = 1$) 的二元材料組合，厚度 $t_{design} = 0.257\ \mu\text{m}$ (對應相移 $2\pi$ 的光學厚度)。GaP 於激發波長 $\lambda = 0.593\ \mu\text{m}$ 處位於其間接能隙 ($E_g \approx 2.26\ \text{eV}$) 之下，近似為低損耗高折射率介質，並具備與現行奈米製程相容的優點。

計算域橫向尺寸為 $S_x = S_y = W_{design} + 2\,d_{pml}$，其中設計區域邊長 $W_{design} = 4.5\ \mu\text{m}$，PML 厚度 $d_{pml} = 0.3\ \mu\text{m}$；縱向尺寸 $S_z$ 依各層厚度與監測面緩衝區疊加而成。空間解析度為 $50\ \text{grid points}/\mu\text{m}$，網格離散化後設計區域共含 $N_x \times N_y = 226 \times 226 \approx 5.1\times10^4$ 個設計自由度。

\subsection{Optimization Schedule}

密度過濾半徑：錐形過濾器過濾半徑 $R$ 由目標最小特徵尺寸 $0.05\ \mu\text{m}$ 與侵蝕閾值 $\eta_e = 0.75$ 反推計算得到。

$\beta$ 排程：$\beta$ 值自$\beta$ 值初始為 $\beta_0 = 4$，先以 $\sqrt{2}$ 為公比呈等比遞增至 128，隨後以 2 為公比倍增至 $\beta_{max} = 1024$。這使結構從初始灰階態逐步過渡至二值化分佈。各階段的迭代次數上限隨 $\beta$ 增大而提升：低 $\beta$ 階段 ($\beta > 32$ ) 收斂較快，給予較少迭代次數；中高 $\beta$ 階段 ($32 = \beta < 1024$) 結構趨於二值化、梯度地形趨於複雜，給予較多迭代次數以確保充分收斂。每一 $\beta$ 階段內記錄 FOM 最佳的迭代結果 (best-so-far snapshot) 作為下一階段的初始結構。

權重係數 $\alpha$：式 (3.16) 中的 $\alpha = 0.1$ 為透過初步試驗決定的經驗值：$\alpha$ 過小時，最佳化初期容易收斂於低耦合功率的局部解；$\alpha$ 過大時，則犧牲模態純度以換取絕對功率，導致遠場模態形狀失真。故 $\alpha=0.1$ 是在兩種失效模式間取得穩定收斂的經驗選擇。

MMA 求解器：最佳化透過 NLopt 函式庫的 MMA 求解器實作，設計變數邊界設為 $0 \le \rho_j \le 1$，停止條件依各 $\beta$ 階段的迭代次數上限觸發\cite{johnson2014nlopt}。

\subsection{Evaluation Configuration}

遠場監測平面：最佳化迴圈中，N2F 轉換計算單一遠場監測平面 ($z = 10\,z_R$，其中 $z_R = \pi w_0^2/\lambda$ 為瑞利長度) 的複振幅，作為 FOM 計算 (式 (3.15)) 與梯度回傳 (式 (3.17)) 的依據。

後處理多重傳播距離取樣：最佳化完成後，以最終最佳密度分佈 $\bar{\rho}^{*}$ 更新設計區域材料並重新執行正向模擬。接著計算傳播距離 $z = k\cdot z_R$ 處的近遠場複振幅分佈，其中 $k \in \{0, 0.1, \dots, 0.9, 1.0, 2.0, \dots, 10.0\}$，共取得 20 組場分佈，藉此觀察目標渦旋光束的相位結構與光學手性是否隨傳播距離穩定維持。

相位纏繞取樣半徑：為驗證遠場光束攜帶理想的軌道角動量拓樸荷 $\ell$，沿遠場強度峰值半徑 $r_{peak} = w_0\sqrt{|\ell|/2}$ 處的圓形路徑取樣場值 ($\ell=0$ 時另取小半徑環以避開中心奇點)。電場投影至 LCP 基底後，計算相位的圓形路徑纏繞數，理論上應等於目標拓樸荷 $\ell$。

手性密度計算平面：式 (3.5) 至 (3.7) 分別應用於兩個觀察平面：設計層正上方監測面 ($z = 0\,z_R$) 評估局部場的手性增強程度；$z = 10\,z_R$ 傳播距離處則驗證近場手性特徵是否於遠場傳播後仍保留。
